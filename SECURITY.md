# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub Security Advisories:
[Report a vulnerability](https://github.com/keelcore/standards/security/advisories/new). Reports stay private until a
fix is available. GitHub's guide:
[privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

When GitHub is not an option, write to [security@byiq.com](mailto:security@byiq.com).

## Supported Versions

The latest release receives security fixes.
